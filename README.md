# calendar-guard

Alertas de escritorio para eventos próximos de Google Calendar, en todas tus
cuentas a la vez. Usa [gogcli](https://github.com/openclaw/gogcli) (`gog`)
como capa de autenticación y acceso a la API, y `notify-send` para las
notificaciones.

La implementación y la documentación de setup llegan en el PR inicial.
